# sistem-panenm

## Deskripsi

Sistem Panen merupakan program Python sederhana untuk menghitung total
pendapatan dari hasil panen berdasarkan nama komoditas, jumlah hasil panen,
dan harga jual per kilogram. Program juga dilengkapi dengan fitur
perhitungan diskon.

## Cara Menjalankan Program

1. Pastikan Python sudah terinstal.
2. Buka file `program_panen.py`.
3. Jalankan program menggunakan Python.
4. Masukkan nama komoditas, jumlah hasil panen, harga per kilogram,
   dan persentase diskon sesuai permintaan program.
